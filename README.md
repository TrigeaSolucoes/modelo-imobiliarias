# Teto Certo Imóveis — site-modelo

Site-modelo **fictício** de Imobiliária de bairro (venda e aluguel) em Belo Horizonte (MG), criado pela [Trígea Soluções](https://trigea.com.br/) para mostrar como pode ficar o site de um negócio desse ramo.
Negócio, pessoas, telefones e endereços são inventados.

Demonstração: https://trigeasolucoes.github.io/modelo-imobiliarias/

Quer um site assim para o seu negócio? Fale com a Trígea: https://trigea.com.br/
